# 开盘缺口量化交易系统 (基于天勤SDK)

## 项目简介

本项目是一个使用 Python 和天勤SDK (`tqsdk`) 开发的量化交易脚本，旨在捕捉股票/期货市场开盘时产生的价格缺口，并根据预设逻辑进行自动化交易。

## 主要功能

*   连接天勤SDK，获取市场行情数据。
*   自动识别开盘缺口（向上跳空或向下跳空）。
*   根据缺口类型和大小生成交易信号。
*   自动执行开仓和平仓订单。
*   包含基本的止盈止损风险管理。
*   记录详细的交易和系统运行日志。

## 文件结构

*   `gap_trader.py`: 主交易逻辑脚本。
*   `gap_trader.log`: 交易及系统运行日志文件 (由脚本自动生成)。

## 环境要求

*   Python 3.7+
*   天勤SDK (`tqsdk`): `pip install tqsdk`
*   Pandas (`pandas`): `pip install pandas`

## 运行方法

1.  **安装依赖**:
    ```bash
    pip install tqsdk pandas
    ```
2.  **配置参数**:
    打开 `gap_trader.py` 文件，根据您的需求修改以下主要配置项 (位于脚本开头部分):
    *   `INSTRUMENTS`: 需要交易的合约代码列表 (例如: `["SHFE.rb2410", "DCE.i2409"]`)。
    *   `MINIMUM_GAP_PERCENTAGE`: 触发交易的最小缺口百分比 (例如: `0.5` 表示0.5%)。
    *   `STOP_LOSS_PERCENTAGE`: 止损百分比 (例如: `1.0` 表示距离开仓价1%)。
    *   `TAKE_PROFIT_PERCENTAGE`: 止盈百分比 (例如: `1.5` 表示距离开仓价1.5%)。
    *   `TRADE_VOLUME`: 每次交易的手数 (例如: `1`)。
3.  **运行脚本**:
    ```bash
    python gap_trader.py
    ```
4.  **注意**:
    *   脚本默认使用天勤SDK的模拟交易环境 (`TqAuth()`)。如果这是您首次运行或未配置实盘账户，它通常会连接到快期模拟。
    *   如需进行实盘交易，您需要拥有已在天勤期货开通的实盘账户，并参照天勤SDK文档正确配置 `TqApi` 的认证信息 (例如: `TqApi(TqAccount("期货公司", "账号", "密码"), auth=TqAuth("信易账户", "信易密码"))`)。 **实盘交易风险自负。**

## 主要逻辑流程

1.  **初始化**:
    *   设置日志记录器 (`logger`)，将日志同时输出到控制台和 `gap_trader.log` 文件。
    *   初始化天勤API (`TqApi`)，连接到交易和行情服务器。
2.  **订阅与准备**:
    *   订阅 `INSTRUMENTS` 列表中所有合约的实时行情 (`quote`) 和K线数据。
    *   检查并加载启动时已有的任何持仓信息，并尝试获取其开仓时的止盈止损（如果是由本策略先前开设）。
3.  **主交易循环 (`run_bot` 函数核心逻辑)**:
    *   持续通过 `api.wait_update()` 等待并处理服务器推送过来的数据更新（行情、订单、持仓等）。
    *   **开盘缺口检测 (`check_opening_gap` 函数)**:
        *   获取每个合约当日的开盘价和前一日的收盘价。
        *   计算价格缺口百分比。
        *   判断是向上缺口、向下缺口还是无显著缺口。
    *   **交易信号生成 (`determine_trade_signal` 函数)**:
        *   如果检测到符合 `MINIMUM_GAP_PERCENTAGE` 条件的缺口：
            *   向上缺口（价格上涨过快）：产生一个“做空（SELL_SHORT）”的信号，预期价格回落填补缺口。
            *   向下缺口（价格下跌过快）：产生一个“做多（BUY_OPEN）”的信号，预期价格反弹填补缺口。
        *   根据开仓价和预设的 `STOP_LOSS_PERCENTAGE`、`TAKE_PROFIT_PERCENTAGE` 计算止损价和止盈价，并考虑合约的最小变动价位进行价格取整。
    *   **订单执行 - 开仓 (`execute_trade` 函数)**:
        *   在产生交易信号后，检查该合约当前是否已有持仓或正在处理的开仓订单。
        *   如果条件允许开仓，则以计算出的目标入场价（通常是当日开盘价）下达一个限价单 (`LIMIT`)。
        *   记录开仓订单的止盈止损目标。
    *   **持仓监控与风险管理**:
        *   **更新持仓状态**: 实时从API获取并更新 `current_positions` 字典，该字典维护了所有当前持仓的详细信息（方向、数量、开仓均价、止盈止损价等）。
        *   **止盈止损检查**:
            *   遍历所有持仓。
            *   获取最新市场价。
            *   如果最新价触及了该持仓预设的止损价或止盈价，则立即执行 `close_position` 函数。
        *   **订单执行 - 平仓 (`close_position` 函数)**:
            *   以下市价单 (`MARKET`) 方式提交平仓指令，确保快速离场。
    *   **活动订单管理**:
        *   跟踪所有已提交但未完全成交的订单 (`active_orders` 字典)。
        *   当订单状态更新（如完全成交、部分成交后被取消），相应地更新 `active_orders` 和 `current_positions`。
4.  **关闭与清理**:
    *   当脚本正常退出或遇到不可恢复的错误时：
        *   尝试取消所有还未成交的挂单（特别是开仓单）。
        *   关闭与天勤服务器的API连接。

## 主要函数详解

本交易系统的核心逻辑主要由 `gap_trader.py` 脚本中的以下函数实现。每个函数都有详细的中文文档字符串（docstrings），说明了其具体功能、参数和返回值。建议直接阅读代码中的文档字符串以获得最准确和详细的信息。

*   **`run_bot(api)`**:
    机器人运行的主入口函数，包含了主要的交易循环和逻辑的编排。

*   **`check_opening_gap(api, instrument_symbol)`**:
    负责在开盘时检查指定合约是否存在价格缺口，并计算缺口详情。

*   **`determine_trade_signal(api, gap_info)`**:
    根据 `check_opening_gap` 返回的缺口信息，结合预设策略，生成具体的交易信号（买/卖、止盈/止损价格）。(注: `api` 参数用于内部调用 `get_tick_size`)

*   **`execute_trade(api, trade_signal)`**:
    执行由 `determine_trade_signal` 生成的开仓交易指令，如下达限价单。

*   **`close_position(api, instrument_symbol, pos_details)`**:
    当达到止盈、止损条件或有其他平仓需求时，执行平仓操作（如下达市价单）。

*   **`get_tick_size(api, instrument_symbol)`**:
    获取指定合约的最小变动价位。

*   **`get_price_precision(tick_size)`**:
    根据最小变动价位计算价格应有的小数点精度。

*   **`round_to_tick(price, tick_size_val)`**:
    将给定的价格按照合约的最小变动价位进行取整。(注: `precision` 是内部从 `tick_size_val` 推断的)

*   **其他辅助函数**:
    脚本中还包含其他辅助管理订单状态、持仓状态等的逻辑，具体请在代码中查看。
